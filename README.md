# Batista Construction Website

Simple static website for Batista Construction.

## Files

- `index.html` - website structure and content
- `mycss.css` - styling and responsive layout
- `script.js` - mobile menu, image lightbox, and email form behavior

## Before publishing

1. Replace `info@batistaconstruction.com` in `script.js` with the real business email.
2. Replace testimonial placeholders with real customer reviews.
3. Add real phone number and city/service-area details in the contact section.
4. Add more project photos to the gallery for better trust and SEO.
